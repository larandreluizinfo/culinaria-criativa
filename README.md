# 🍳 Culinária Criativa

Jogo para até 10 jogadores! Cozinhe com o tema sorteado, corra contra o tempo sorteado, avalie com até 5 estrelas e veja o pódio 🥇🥈🥉

## Como jogar
- **Local:** todos no mesmo aparelho
- **Online 🌐:** um cria a sala e passa o código de 4 letras, os amigos entram cada um no seu celular/PC

## Jogar
Abra o link do GitHub Pages ou o `index.html` no navegador.

Feito com ❤️ em HTML + CSS + JS + PeerJS.
